# Gif Studio

**Gif Studio** è un editor grafico portatile avanzato per modificare immagini singole e GIF animate a livello professionale.

## 🚀 Nuove Funzionalità (v1.0.4)
- **Strumento Forme Geometriche**: Disegna quadrati, rettangoli, cerchi (ellissi) e linee rette direttamente su tela. Le forme appaiono su un nuovo livello isolato, con la possibilità di customizzare colore del bordo, spessore e riempimento interno!
- **Strumento Selezione Lazo (Taglio Pixel)**: Traccia una selezione a mano libera o rettangolare attorno a una porzione dell'immagine, estraendo magicamente i pixel dal livello originale e isolandoli in un nuovo livello tutto tuo (funzione *Ritaglia ed Estrai Livello*). 
- **Estetica e UX**: Aggiornate icone vettoriali per i nuovi strumenti per una UI più pulita, e sottomenu dinamici (accordion) che si aprono sotto lo strumento attivo.
- **Tutorial Estesi**: Documentazione integrata aggiunta a tutti i sottomenu e pulsanti, compresi i nuovi strumenti appena inseriti.

## 💻 Installazione

L'applicazione può essere installata sui sistemi operativi Windows tramite l'installer in formato eseguibile:
1. Assicurarsi di scaricare l'ultimo eseguibile di setup (es. `GifStudio_Setup.exe`).
2. Avviare l'installazione. Verranno richiesti i privilegi di amministratore per poter installare il certificato root `gifstudio-public.cer` usato per firmare l'applicazione.
3. Al termine dell'installazione si aprirà automaticamente il programma.

*Note Tecniche: L'app è basata su stack web-tecnologico (HTML5, JavaScript, Vanilla CSS) all'interno di un core nativo Electron per alte prestazioni su computer desktop.*
